# Contributing

Thanks for your interest in contributing to NeoArcadeOS.

## How to contribute

- fork the repository
- create a feature branch
- make your changes
- test locally when possible
- open a clean pull request with a clear description

## Good contribution ideas

- improve boot flow and startup UX
- improve emulator or ROM configuration
- refine interface consistency and visual quality
- improve documentation and setup instructions
- help with compatibility and system testing

## Pull request expectations

Please keep pull requests focused and easy to review. Include:

- a short summary of the change
- why the change is needed
- relevant screenshots or notes if the change affects the UI

## Code of conduct

Be respectful, constructive, and helpful. We aim to keep the project collaborative and welcoming.

## Important note

This project is still evolving, so suggestions that make the experience more polished, stable, or user-friendly are especially valuable.
